EVE compares the callback URL against your application's registration as an exact string, and an application has exactly one — so no application can be shared between installs. This one needs its own, which takes about a minute to create.

  1. Open the EVE Developer Portal and create an application.
  2. Set Connection Type to Authentication & API Access. "Authentication Only" grants no data access.
  3. Set the Callback URL to exactly this — no trailing slash:
    {{ callback_url }}
  4. Add all {{ scopes|length }} permissions below.
    Show the list
    Select them all now: an application can only ever request the scopes assigned at registration, so adding one later means a new application — and a new Client ID invalidates every character already added.
  5. Copy the Client ID and paste it below. Ignore the secret key — this is a PKCE flow and no secret is ever sent.

Deploying this on a server instead? Set the EVE_CLIENT_ID environment variable — this page is not served off localhost.
